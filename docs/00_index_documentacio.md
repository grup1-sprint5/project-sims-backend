# Índex de documentació del projecte SIMS Backend

Aquest paquet de documents explica el projecte des de diferents nivells: executiu, funcional, tècnic i conceptual.

## Documents inclosos

1. [`01_resum_executiu_i_context.md`](./01_resum_executiu_i_context.md)
   - Visió general del producte, problema que resol i valor per negoci.

2. [`02_funcionalitats_i_fluxos_usuari.md`](./02_funcionalitats_i_fluxos_usuari.md)
   - Què pot fer cada tipus d’usuari i com són els fluxos principals.

3. [`03_arquitectura_tecnica_i_dades.md`](./03_arquitectura_tecnica_i_dades.md)
   - Arquitectura, multi-tenant, components i model de dades.

4. [`04_api_seguretat_i_permisos.md`](./04_api_seguretat_i_permisos.md)
   - Autenticació, autorització, rutes API i control d’accés.

5. [`05_operacio_manteniment_i_troubleshooting.md`](./05_operacio_manteniment_i_troubleshooting.md)
   - Execució local, operació, scheduler i diagnòstic d’errors freqüents.

6. [`06_conceptes_abstractes_i_ia.md`](./06_conceptes_abstractes_i_ia.md)
   - Explicacions no tècniques de conceptes (inclòs “per què una IA pot tindre memòria”).

7. [`07_entorn_de_testing.md`](./07_entorn_de_testing.md)
   - Configuració de l'entorn de testing, creació de la BD de test i execució dels tests.

## Com usar aquests documents

- Si has de preparar una presentació: comença per `01` i `02`.
- Si has de defensar decisions tècniques: revisa `03` i `04`.
- Si has de fer demo o manteniment: usa `05`.
- Si has de comunicar idees a públic no tècnic: usa `06`.
